# 보이스그램 · Voicegram

말이나 글로 이야기를 만들고, 피드에서 서로의 일상을 나누는 SNS 베타.

## 화면과 흐름
- 홈: 전체 피드 / 팔로잉 피드, 사진·영상·글 게시물, 좋아요·댓글·저장.
- 둘러보기: 게시글 및 이름 검색, 이웃 프로필과 팔로우.
- 만들기: **말로 만들기 / 글로 쓰기 → 미리보기 → 피드에 게시**. 사진·영상은 선택 사항.
- 알림: 내 게시물의 좋아요·댓글, 새 팔로워. 새로고침 방식이며 푸시 알림은 아님.
- 프로필: 이름·소개·이모지 편집, 내 게시물, 저장한 글. 홈과 내 프로필 모두 작성 진입 버튼 제공.

## 연결 상태와 범위
배포 대상은 Netlify `jini-nova / jini-voicegram`: https://jini-voicegram.netlify.app

소규모 비공개 테스트 단계. 팀 SSO와 테스트 접근 코드가 필요하며, 기존 기기별 테스트 프로필을 유지한다. 카카오 회원 로그인 연동은 구현했으며, 키 등록과 실제 계정 검증 후 활성화한다. 게시물·댓글·좋아요·팔로우·차단·신고는 서버에 저장한다. 예시 글은 명시적으로 표시하며 가짜 반응 수를 넣지 않는다. 임시 작성과 저장 목록은 기기에 보관한다.

OpenAI 대화 및 이미지 생성 어댑터는 연결되어 있다. AI 생성은 별도 비용 확인 후 실행한다. Runway 영상 어댑터는 구현했으나 별도 API 설정과 실생성 검증이 필요하다. 무음 6초 사진 영상은 지원 브라우저에서 로컬로 만들 수 있다. 마이크 권한과 음성인식은 브라우저 및 기기에 따라 다르다.

인스타그램 OAuth/게시 어댑터는 보존했지만 계정 연결은 사용자 지시로 보류했다. 이번 SNS 피드는 보이스그램 자체 커뮤니티다. 다른 프로젝트인 지니오토스테이션은 수정하지 않는다.

## 서버
- `/api/chat`: 대화, 접근 코드 확인, signed tester session.
- `/api/studio`: AI 이미지/영상 요청 및 상태 확인.
- `/api/social`: 테스트 프로필, 게시물, 반응과 미디어. Netlify Blobs의 강한 일관성 및 ETag 조건부 쓰기로 갱신.
- `SOCIAL_SESSION_SECRET`: 테스트 접근 코드와 다른 서버 전용 서명키. 최소 32자. 프로필 쿠키를 보호하며 절대 클라이언트에 전달하지 않는다.

카카오 실계정 검증·탈퇴/연결 해제 처리, 정책/신고 운영, 데이터베이스 확장, 사용량 결제는 공개 출시 전 필수다. 상세 구현 한도와 검증 상태는 [social-beta.md](docs/social-beta.md)를 참고한다.

## 개발 및 검증
```sh
node node_modules/typescript/bin/tsc --noEmit
node --test tests/social.test.mjs
npm run build:netlify
node scripts/package-netlify.mjs
```

`outputs/netlify-deploy`를 기존 Netlify 사이트에 수동 배포한다. GitHub 저장과 Netlify 자동 배포 연결은 별개이며 자동 배포는 아직 설정하지 않았다. 기존 Sites 서버 어댑터는 과거 경로이며, 이번 커뮤니티 API는 Netlify 배포를 기준으로 한다.

로컬 Chromium에서 360/390/430/768/1440px 가로 넘침, 좋아요·댓글·팔로우, 글 게시, 두 사용자 간 표시, 알림, 프로필 수정과 작성 진입을 테스트 API로 확인했다. 라이브 다중 기기, 실제 마이크 인식과 영상 재생은 별도 테스터 검증이 필요하다. 실제 사용자 데이터나 유료 AI 요청은 이번 테스트에서 생성하지 않았다.

## 카카오 · 토스 준비
카카오 간편로그인 화면과 서버 OAuth, 로그아웃, 작성 중 로그인 왕복 복원을 추가했다. 토스 v2 주문서형 테스트 결제 어댑터는 live 키를 거부하며 실제 결제는 비활성화 상태다. 두 서비스의 API 키가 미등록되어 실계정/실상점 검증은 미완료다. 등록할 URL과 실행 순서는 [kakao-toss-setup.md](docs/kakao-toss-setup.md)를 참고한다.
