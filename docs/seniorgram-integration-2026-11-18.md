# 시니어그램 → 보이스그램 통합

기준: 2026-11-18, 한국 시각. 대표 지시에 따라 **보이스그램을 단일 개발 제품으로 운영**한다. 시니어그램의 별도 개발과 애플 등록 진행은 중단한다. 양쪽 `AGENTS.md`와 README에 이 방향을 기록했다.

## 이번에 옮긴 기능

| 시니어그램에서 가져온 흐름 | 보이스그램 구현 | 범위 |
| --- | --- | --- |
| 상황 고르기 → 이름 넣기 → 카드 완성 | `greeting-card-picker.tsx`, `greeting-card.ts`, 기존 Canvas 렌더러 | 안부·생일·감사·응원 4종. 받는 분·보내는 분·문구·선택 사진. 1080px 정사각 이미지 |
| 일상 인사 요청을 유료 AI 화면 대신 무료 카드로 연결 | 음성 명령과 글로 적은 카드 요청 | 전체 문장이 명확한 카드 명령일 때만 연결. 이야기 속 인용은 일반 글로 유지 |
| 이름·문구 변경, 카드 완성 명령 | 기존 음성 게시 컨트롤에 연결 | 실제 발화 인식률은 기기별 검증 필요. 게시 확정은 기존 별도 확인 유지 |

| 큰 글씨로 쉽게 작성 | 기존 큰 글씨 설정을 작성·카드 화면까지 확장 | 모바일 가로 넘침과 실제 터치 조작은 새 버전 실기 확인 필요 |

참조 원본: Seniorgram `4d6b0e907cc43a4017d2fd76d84539bc003aca58`의 `public/studio/voice.js`, `media-actions.js`, 카드 편집 흐름. React/TypeScript 구조에 맞춰 옮겼으며 시니어그램 웹사이트 전체를 중첩하지 않았다.

## 보존과 다음 통합 후보

- 시니어그램의 기존 배포·코드·DB·App Store 항목을 보존했다. 앱 제출·리소스 삭제·구독 해지·데이터 이전은 실행하지 않았다. 시니어그램의 자동 iOS 빌드 트리거는 중단하고 수동 재현 경로를 남겼다.
- 보이스그램의 기존 계정·피드·결제·iOS Bundle ID를 기준으로 계속 개발한다. 별도 제품의 비밀값이나 회원 레코드를 복사하지 않는다.
- 시니어그램의 여러 작품 보관함, 28개 상황과 30개 디자인, 처음 배우기 안내, 목소리가 포함된 카드 등은 이번 이식에 포함하지 않았다. 기존 작품을 열고 내보낼 수 있는 원본을 유지한다.
- 기존 두 사이트의 브라우저 보관함은 출처가 달라 자동 이전되지 않는다. 향후 별도의 내보내기/가져오기 기능을 설계하고 데이터 보존을 검증한다. 현재 보이스그램에는 기존 단일 작성 초안 보관 기능이 유지된다.
- 보이스그램의 기존 iOS 프로젝트에 웹 카드 기능이 반영되는 구조다. 시니어그램의 별도 SwiftUI 프로젝트를 덮어쓰지 않았으며, 새 iPhone 빌드·TestFlight 검증을 했다고 간주하지 않는다.

## 확인한 결과

- TypeScript 검사 통과.
- 전체 자동검사 **70개 통과**, 실패 0개. 새 통합 검사 5개는 명령과 인용 구분, 사진 보존, 공유 취소/중복, 파일 쓰기 실패/재시도, 다운로드 요청 표시를 검사한다.
- Netlify 운영용 빌드 통과.
- 연결된 동일 크롬 제어는 originating browser context 오류로 접근 불가. 다른 브라우저로 바꾸지 않았다. 새 UI의 실제 카드 생성·발화·파일 선택·휴대폰 저장·카카오톡 전송은 미검증이다.
- GitHub 반영과 운영 배포 결과는 실제 커밋/배포 기록으로 별도 확인한다.

공유 구현 기준(2026-11-18 확인): W3C Web Share API https://www.w3.org/TR/web-share/ 및 WebKit 사용자 동작 활성화 https://webkit.org/blog/13862/the-user-activation-api/ . 공유창 선택이 수신자에게 전달 완료되었음을 뜻하지 않으며, 파일 준비 후 사용자의 버튼 동작으로 공유를 요청한다.
