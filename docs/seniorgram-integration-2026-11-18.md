# 시니어그램 기능 통합 후보

기존 원본은 bidomoon/jini-seniorgram main에 보존한다. 기존 회원·작품·구독·앱 식별자 및 운영 데이터의 이동·삭제는 수행하지 않았다.

## 구현

- 시니어그램의 준비된 카드 문구 30종을 보이스그램 편집기에 연결. 카드 선택 후 교체 확인을 거치며 사진을 유지한다. 유료 AI를 호출하지 않는다.
- 카드·음성·보관/공유 3개 연습 안내와 기기별 진도 저장.
- 완성 PNG와 MP4·MOV·WebM을 명시적으로 보관하는 IndexedDB 작품 보관함. 프로필 및 점검 공간별로 목록·조회·삭제를 분리한다.
- 전체 기기 30개·100MB, 파일별 25MB 제한. 반복 저장은 덮어쓰지 않고, 메타데이터와 파일을 동일 트랜잭션에 저장한다.
- 작품 재열기·재생·파일 저장·시스템 공유창·삭제 확인. 시스템 공유를 전송 완료라고 표시하지 않는다.
- 기존 큰 글씨를 편집기와 연습·보관함에도 적용. 기존 게시글 읽어주기는 유지.

## 검증 상태

타입 검사, 기존 자동검증 65개, 새 보관함 검증 5개 및 Netlify 운영 빌드 통과. 새 화면의 브라우저 조작과 아이폰 마이크·공유 시험은 아직 실행 전이다. 운영 배포와 스토어 제출 완료를 뜻하지 않는다.

보관함 파일은 이 브라우저에만 남는다. 별도 도메인의 기존 시니어그램 IndexedDB 자료를 자동으로 읽거나 복제하지 않는다. 기존 앱 스토어 식별자를 보이스그램으로 바꾸지 않는다.
