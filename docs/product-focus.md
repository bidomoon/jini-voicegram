# 보이스그램 제품 방향

2026-11-18 매버릭 결정.

보이스그램은 말로 글·사진·영상을 만들고 피드에서 교류하는 독립 SNS다. 가족 간 안부 전송 서비스로 제품을 좁히지 않는다. Instagram처럼 이용하되 음성으로 쉽게 참여하는 경험을 지향한다. 외부 Instagram 자동 게시를 완료된 기능으로 설명하지 않는다.

시니어그램의 별도 신규 개발과 신규 스토어 제출 준비는 중단한다. 기존 저장소·서비스·회원·작품 데이터는 보존하며, 필요한 기능만 보이스그램으로 통합한다. 지니캡은 별개 제품으로 개발·애플 준비를 계속한다. 두 앱 모두 최종 실기기 확인 뒤 각자 심사 제출한다.

핵심 우선순위는 작성 → 내용 확인 → 게시 → 피드 탐색 → 읽어주기 → 반응과 댓글이다. 현재 구현 여부와 향후 목표는 구분한다. 인사 카드·연습 안내·기기 작품 보관함은 참여를 돕는 보조 기능이다. 가족 초대·가족 수신을 필수 흐름으로 만들지 않는다.

시장 검증은 실사용자의 도움 없는 첫 게시 완료, 다음 주 재게시, 피드 탐색과 다른 사용자와의 실제 교류, 유료 기능·기관 도입의 실제 지불 의향을 본다. 다운로드와 앱스토어 승인만으로 시장성·투자 유치를 입증했다고 하지 않는다.
