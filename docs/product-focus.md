# 보이스그램 제품 기준

2026-11-18 한국 시각, 매버릭의 최종 설명을 기준으로 한다.

보이스그램은 **남녀노소 누구나 말로 콘텐츠를 만들어 올리는 독립 SNS**다. 대상은 전 연령대이며 시니어는 여러 사용자층 중 하나다. 가족 수신이나 가족 초대가 필수인 서비스로 설명하지 않는다.

인스타그램처럼 익숙한 게시·피드·공유·좋아요·댓글·팔로우·프로필·링크 전파 흐름을 제공하되, 핵심 차이는 **업로드할 내용을 말로 작성하고 확인해 게시하는 것**이다. 모든 메뉴를 음성으로 조작해야 한다는 요구로 확대 해석하지 않는다. 외부 Instagram 계정에 자동 업로드하는 기능과도 구분한다.

## 화면과 이미지

- 음성 작성 → 내용 확인 → 게시를 만들기 화면의 중심에 둔다.
- 큰 글씨·처음 배우기·인사 카드는 필요한 사람이 여는 선택 기능으로 둔다.
- 시니어 전용 이미지나 가족 안부를 대표 시각물로 쓰지 않는다. 취미·여행·음식·운동·반려동물·일상 등 다양한 관심사를 다룬다.
- 작성 방법을 바꾸거나 선택 기능을 여닫아도 현재 작성 내용·사진·영상이 사라지지 않게 한다.

## 개발·투자 설명에서 지킬 범위

현재 코드에는 글·사진·영상 게시, 좋아요·댓글·팔로우, 검색·프로필·저장, 게시물 링크와 공유, 신고·차단·계정 관리가 있다. 구현과 실제 운영 시험은 구분한다. DM·라이브·스토리 등 Instagram의 전체 기능이 이미 제공된다고 설명하지 않는다. 공개 가입·실기기·스토어 심사와 매출·사용자 유지 실적도 각각 확인한다.

시장 검증은 연령대를 나눠 도움 없는 첫 게시 완료율, 음성 작성 이용률, 반복 게시·재방문, 사용자 간 반응·공유, 실제 지불 의향과 운영 원가를 확인한다. 전 연령 대상이라는 방향을 특정 연령만의 수요 가정으로 바꾸지 않는다.

시니어그램의 별도 신규 개발은 중단하고 기존 자료·데이터를 보존한다. 지니캡은 별개의 제품으로 계속 개발한다. 이 문서가 다른 앱의 중단을 뜻하지 않는다.

## 앱 안의 이미지 제작 — 추가 지시

우선순위는 이미지 샘플·문구 → 음성으로 선택·변경 → AI 이미지 생성/수정 → 결과 선택 → 미리보기 → 게시다. 외부 제작 앱으로 사용자를 보내지 않고 이 안에서 흐름을 잇는다. 샘플 자체 적용과 Canvas 문구 변경에는 새 유료 생성 요청을 보내지 않는다. AI 생성은 한 번에 1장씩 비용 확인 후 실행하고, 이전 결과 선택에는 재생성하지 않는다.

영상 업로드는 유지한다. 기존 AI 영상 어댑터와 웹 기능도 보존하되, 새 상세 영상 편집·샘플 개발보다 이미지 흐름을 우선한다. 새 서비스는 서버에서 검토한 어댑터로 등록하고, 클라이언트가 임의 주소·모델·키를 넣어 비용 발생 경로를 바꾸지 못하게 한다. 기존 OpenAI 이미지 모델과 low 품질 기본값을 유지하고, 최신 모델이라는 이유만으로 운영 모델을 교체하지 않는다.
