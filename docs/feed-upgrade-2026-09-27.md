# 보이스그램 피드 개선 · 2026-09-27

## 배포 위치

- 사용자가 이전한 팀: `jini-sale-item` (`6ab8a7e0e5118b1fc66c6908`).
- 프로젝트: `jini-voicegram` (`e78fcfa6-0dd7-45e0-a3e1-e417ce52b91c`).
- 주소: https://jini-voicegram.netlify.app
- 같은 프로젝트 ID와 주소 유지. 기존 10개 환경 변수의 존재·스코프 확인. 비밀값은 문서에 저장하지 않음.
- 팀 로그인 보호 유지. 공개 출시·인스타그램 연결·실결제 활성화는 이번 변경 범위가 아님.
- 서버의 기존 게시물을 직접 읽거나 쓰는 운영 테스트는 수행하지 않음.

## 사용자 경험

- 모바일 피드를 화면 너비로 확장하고 사진 아래에 좋아요·댓글·공유·저장 배치.
- 사진 두 번 누르기로 좋아요. 키보드·화면 읽기 사용자는 기존 좋아요 버튼 이용.
- 좋아요 즉시 표시, 실패 시 복구. 새로고침 중 발생한 변경을 오래된 응답이 덮어쓰지 않음.
- 긴 글 펼치기/접기, 글 듣기, 댓글 미리보기와 전체 댓글 이동.
- 댓글은 모바일 하단 시트로 열림. 이모티콘 입력, 전송 중 입력 잠금으로 새 댓글 유실 방지.
- 운영체제 공유 또는 링크 복사. `?post=<id>`로 접근하면 로그인 후 해당 글 열기. 삭제·차단된 글은 표시하지 않음. 공유 대상에게도 테스트 접근 권한 필요.
- 탐색·프로필 모바일 3열 그리드, 팔로워·팔로잉 목록, 홈으로 돌아올 때 읽던 위치 복원.
- 홈 피드 최초 12개 렌더링, 더 보기로 12개씩 추가. 서버 응답 자체의 페이지 분할은 아직 아님.

## 성능

- 작성·결제 화면은 동적 청크로 분리, 홈 진입 시 받지 않음. 첫 이미지 우선 로드, 이후 이미지 지연 로드.
- 영상은 화면 근처에 왔을 때 소스를 연결. 화면 밖·다른 대화창·백그라운드에서는 일시정지. 자동 재생 없음.
- 프로필/게시물/좋아요/댓글/차단을 매 게시물마다 재검색하던 피드 정리를 Map/Set 기반으로 변경. 저장 구조·접근 제어·동시성 처리는 유지.
- 초기 JS 원본: 358,076 → 317,324 bytes (약 11.4% 감소).
- 같은 Python gzip 설정: JS 111,436 → 99,877 bytes (약 10.4% 감소). CSS는 209,518 → 215,787 bytes. 전체 최초 JS+CSS 원본은 약 6.1% 감소.
- 로컬 CPU 비교: 프로필 500 / 게시물 300 / 좋아요 15,000 / 댓글 3,000. 25회 중앙값 24.38 → 1.73ms (약 92.9% 감소).
- 위 수치는 로컬 빌드와 계산 측정. 실제 휴대폰의 인터넷·서버 저장소 시간을 포함한 체감 속도 수치가 아님.

## 검증과 재사용

- `node --test tests/*.test.mjs`: 18개 테스트.
- `tests/social-projection.test.mjs`: 이전 구현과 새 구현의 전체 응답 비교. 차단 양방향, 삭제, 정렬, 수치, 댓글, 알림 한도, 신규 사용자, 원본 불변성.
- `node scripts/benchmark-feed.mjs`: 같은 데이터 규모로 성능 비교 재현. 시간 기준을 테스트 통과 조건으로 사용하지 않음.
- `tests/browser-feed.mjs`: 프로덕션 빌드 + 실제 social 함수 + 독립 메모리 저장소. 좋아요 지연·실패·새로고침 경합, 댓글, 링크, 분할 렌더링, 스크롤, 영상, 팔로워 목록 확인.
- `tests/browser-creation.mjs`: 실제 studio/social/chat 함수 + 가상 외부 AI 응답. 생성 비용 확인·그림 수정·초안 복구·중복 생성/게시 방지·로컬 6초 영상 회귀 확인.
- 별도 인증 UI 회귀: 카카오 미설정, 가상 OAuth 후 초안 복귀, 로그아웃, 결제 준비 상태와 테스트 승인 1회 처리.
- 360 / 390 / 430 / 768 / 1440px. 프로덕션 CSS를 사용해 모바일 댓글창과 가로 넘침 확인.
- 실제 사용자 글·댓글 생성 없음. 유료 AI 호출·실결제 없음. 모바일 키보드와 Web Share의 실제 기기별 동작은 출시 전 기기 테스트 필요.
