# 화면과 생성 흐름 개선 · 2026-09-27

목적: 사용 편의, 단순한 흐름, 가벼운 재미, 일상과 상상을 모두 담는 다양성.

## 화면 비교와 반영

- 기존 홈: 인사말·만들기·안내가 따로 쌓여 첫 게시물이 늦게 보임. 새 홈은 두 가지 작성 버튼을 한 카드로 모으고 안내 높이를 줄임. 390px QA 화면에서 첫 게시물 시작 위치는 약380px에서330px로 줄었음.
- 기존 만들기: 대화 입력과 게시글 입력이 동시에 비어 있어 어디에 입력할지 모호함. 새 만들기는 큰 마이크를 중심으로 시작하고, 받아 적은 내용이 생겼을 때 게시글 입력을 보여줌. 직접 글로 쓰기는 별도 탭.
- 기존 둘러보기: 텍스트 목록과 빈 화면 중심. 사진·글·영상 필터, 미리보기 타일, 상세 보기, 사람 검색을 제공. 콘텐츠가 없을 때만 명시된 예시를 보여줌.
- 여섯 가지 이야깃거리: 작은 행복, 반려동물, 음식, 산책, 추억, 상상. 선택은 질문만 바꾸며 기존 초안을 덮어쓰거나 AI 요청을 실행하지 않음.
- 프로필의 모아보기/크게 보기, 댓글 이모티콘 넣기, 기기 음성으로 게시글 읽어주기, 큰 글씨 설정 추가. 읽어주기는 버튼을 눌러 시작하고 화면 이동 시 중지.

공식 참고 자료: Instagram 창작 부담을 낮추는 방향과 Threads의 관심사/피드 탐색 기능을 참고하되, 본 앱의 규모에 맞춰 단순한 필터와 작성 진입을 구현함. 타사 서비스 화면을 그대로 복제하거나 추천 알고리즘을 구현했다고 주장하지 않음.

## ‘예쁜 고양이 그려줘’ 오류

원인: 비연결 대화의 기본 경로와 직접 게시글 입력이 생성 명령을 일반 문장으로 처리함. 이미지 없이 텍스트 미리보기가 열림.

수정:
- 명확한 ‘그려줘’ 및 사진/영상 생성 요청을 판별. 일상 서술과 부정 명령은 제외.
- 말하기·대신 입력하기·글 입력 모두 생성 요청으로 연결. 게시글과 생성 지시문은 분리.
- 테스트 인증 상태와 서비스 연결 상태를 구분하고 필요한 경우 생성 화면에서 접근 코드 입력.
- 비용 확인 후에만 기존 이미지 API 호출. 이미지 응답은 즉시 미리보기에 표시.
- 빈 이미지, 미완성 영상, 아직 실행하지 않은 AI 요청은 게시 확인으로 우회 불가.
- 오인식할 경우 ‘글로만 쓸게요’로 일반 게시글 작성 가능.
- 생성에 실패하면 안내하며 자동 재시도하지 않음. 세션 만료 시 다시 연결 가능.

## 검증과 한계

- TypeScript, 13개 서버/의도 판별 테스트 통과.
- Chromium QA: 360/390/430/768/1440px. 탐색 필터·상세, 주제와 초안 보존, 음성/글 생성 요청, 인증/비용 확인, 응답 미리보기, 글로만 쓰기, 빈 이미지 방지, 좋아요/댓글, 큰 글씨, 프로필 전환 검증.
- 브라우저 QA는 음성 인식과 API 응답을 모의 처리. 실제 마이크·기기 음성·유료 생성·외부 SNS 게시를 검증했다는 뜻은 아님. 이번 변경 검증에서 유료 API 호출은 없음.
- 카카오·토스 실연결, 공개 배포 접근 제한, 영상 API 미연결 상태는 별도 준비사항.
