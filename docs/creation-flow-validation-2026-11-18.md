# 보이스그램 제작 흐름 및 검증 기록

2026-11-18 한국 시각.

## 제품 방향과 개발 순서

- 전 연령 대상 SNS. 글·사진·영상 게시, 댓글·좋아요·팔로우·링크 공유를 기반으로 말로 콘텐츠를 제작하는 흐름을 강화한다.
- 우선순위는 이미지 샘플 → 음성 또는 클릭 선택 → 문구 수정 → 미리보기 → 명시적 게시다. 기존 영상 업로드는 유지하고 AI 영상 생성의 상세 고도화는 후속으로 둔다.
- 시니어그램의 독립 개발은 중단 상태를 유지한다. 큰 글씨·카드·학습 안내는 보이스그램의 선택 기능이다.

## 이번 개발 변경

- ‘샘플 1번 적용’과 ‘완성 1번 선택’을 별도 인식한다. 두 목록이 함께 보일 때 모호한 번호는 이미지를 바꾸기 전에 어느 목록인지 안내한다.
- 샘플 문구의 클릭·음성 입력을 같은 처리 함수로 연결했다. 지나치게 긴 복합 문구는 이미지를 바꾸기 전에 거절하며, 첨부 영상이 이미지 명령으로 사라지지 않도록 보호한다.
- 계정 삭제 가능 여부를 로딩·사용 가능·설정 미연결·연결 오류로 구분하고 재확인 버튼을 제공한다. 완료 결과에서 계정·게시물 삭제와 첨부 원본·연결 정보 정리 대기를 구분한다.
- 계정 삭제 시 같은 계정의 다른 기기 세션도 즉시 정리한다. 정리 실패는 대기로 반환하며 삭제 계정의 접근은 계속 차단한다. 다른 사용자의 세션은 보존한다.
- 배포용 검증은 tests/*.test.mjs를 자동 발견해 새 이미지 검사도 누락하지 않는다.

## 검증 경계

유료 이미지 API 호출, 실제 사용자 계정 삭제, 외부 발송은 이번 검사에 사용하지 않는다. 서버 검사는 임시 메모리 저장소와 제공자 응답 대역으로 수행한다. 실제 마이크, 클릭과 음성의 화면 종단 동작, iPhone 저장·공유, 로그인 연결·삭제는 별도 검증 대상이다.

연결된 브라우저 확장의 originating-context 오류로 운영 UI 검증을 시작하지 못했다. 클라우드 브라우저는 로컬 개발 서버 연결을 거절하여 새 UI의 화면 조작 검증은 미완료다. 이 제한을 테스트 통과나 배포 성공으로 대체하지 않는다.

애플 공식 삭제 안내 확인: https://developer.apple.com/support/offering-account-deletion-in-your-app/

검증 결과: 서버·모듈 자동검증 78개 통과, TypeScript 검사 및 Netlify 프로덕션 빌드 통과. 신규 명령 식별과 서버 계정 삭제·세션 정리는 자동검증 대상이며 실제 마이크 인식이나 화면 종단 검증 결과가 아니다.
