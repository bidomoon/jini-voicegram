# 운영자 실사용 점검 보강 — 2026-11-15

## 범위

기존 Netlify 팀 로그인에서 검증된 소유자 본인은 별도 초대 코드를 다시 입력하지 않고 보이스그램 운영자 프로필로 시작한다. 카카오 회원과 기존 기기 테스트 프로필은 합치지 않는다. 이 변경은 일반인 공개 가입을 열거나 팀 로그인 보호를 해제하지 않는다.

운영자 세션은 임의 헤더를 신뢰하지 않고, 매 요청 Netlify가 검증한 사이트·사용자가 원래 세션과 일치하는지 다시 확인한다. 소유자 권한 해제·로그아웃·만료 후 기존 앱 쿠키만 복사해 사용할 수 없다. 소유자 시작은 유료 AI 대화용 테스트 세션을 발급하지 않는다.

## 점검 공간

설정의 ‘실사용 점검 공간 열기’는 `voicegram-selftest-v1` 저장소와 `/api/selftest`를 사용한다. 실제 피드의 `voicegram-social-beta-v1`과 독립적이다. 글·사진·영상, 프로필·반응과 미디어 URL도 분리한다. 검증용 사진과 무음 2초 영상 다운로드를 제공한다. 이 영상은 ffmpeg의 테스트 패턴이며 실제 사용자 영상이나 음성이 아니다.

점검 공간에서는 외부 공유·계정 삭제·운영 신고 변경·결제 도구를 사용할 수 없고 새 유료 AI 생성도 실행하지 않는다. 실제 피드로 전환하기 전에 작성 중 자료를 저장하고 초안 저장 위치를 구분한다. 정리 작업은 점검 중 만료된 업로드 조각도 대상으로 한다.

## 계정 관리 경로

`/account/manage`, `/account/delete`에서 계정 관리 화면으로 진입한다. 로그인 뒤에도 계정 관리로 돌아온다. URL을 여는 것만으로 계정을 삭제하지 않으며 본인 로그인·확인 문구가 필요하다. 외부 공개 접근은 기존 팀 보호 설정의 영향을 받으므로 이 경로 구현만으로 앱마켓의 공개 삭제 요청 조건을 충족했다고 주장하지 않는다.

계정 삭제 시 실제 피드와 해당 사용자의 점검 공간 기록을 함께 종료한다. 사진·영상은 소유자를 확인하며 정리하고, 다른 사용자의 파일은 삭제하지 않는다. Netlify 자체 계정을 삭제하거나 로그아웃시키는 기능은 아니다.

## 검증 구분

자동검증은 소유자 로그인·세션 재사용 차단, 기존 카카오 경로 보존, 원본/점검 저장 분리, 미디어 경로 분리, 양쪽 계정 기록 정리를 포함한다. 배포 후 실제 브라우저 결과는 별도 릴리스 기록에 남긴다. 실제 마이크·카메라 시험과 입력칸 명령 전달은 구분한다.
