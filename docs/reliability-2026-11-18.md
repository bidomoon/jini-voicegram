# 보이스그램 작성·통신 안정성 개선

기준: 2026-11-18 한국 시각. 전 연령 음성 SNS의 이미지 제작·게시 흐름을 유지한다.

## 수정한 동작

- 글을 모두 지운 상태도 저장해, 새로 열 때 이전 글이 되살아나지 않게 했다.
- 입력 직후 화면 이동, 탭 숨김·페이지 이탈에서 마지막 초안을 바로 저장하도록 요청한다. 저장에 실패하면 저장 완료로 표시하지 않고 재시도할 수 있게 한다. 기기 강제 종료·저장 공간 오류에서 절대 보존을 보장하는 기능은 아니다.
- 저장을 순서대로 처리하고, 이전 저장 응답이 최신 수정의 상태를 저장 완료로 덮지 않게 한다. 게시 성공 후 대기 중인 자동 저장이 초안을 다시 만들지 않게 한다.
- 사진을 불러오는 중 다른 사진·영상·결과·작성 방식을 선택하면 늦게 도착한 이전 사진이 선택을 덮지 않게 한다.
- 피드·로그인·게시·계정 삭제·AI 생성·샘플·완성 파일 조회에 응답 본문까지 포함하는 시간 제한을 적용했다. 통신 복구 시 피드와 로그인 상태만 다시 읽으며 쓰기 요청을 자동 반복하지 않는다.
- AI 생성 응답이 유실되면 기존 요청번호와 pending/unknown/failed 상태를 유지한다. 결과 조회로 복구하고 새 생성은 별도의 비용 확인을 거친다.
- 오프라인 안내와 재연결 뒤 피드 갱신을 추가했다. 점검 공간과 실제 피드의 경로를 섞지 않는다.

## 반복 검증

`npm run check`로 TypeScript 검사 → 전체 테스트 → Netlify 프로덕션 빌드를 실행한다. 88개 검사 통과, 실패 0개. 저장 경합·빈 초안·저장 실패/재시도·게시 후 저장 취소·전송 및 본문 시간 초과·인증 만료·잘못된 응답·AI 결과 상태·파일 바이트를 포함한다. 실제 유료 API·사용자 계정 삭제·외부 발송을 실행하지 않는다.

테스트가 직접 사용하는 esbuild를 개발 의존성에 명시했다. 기존 npm 잠금 파일에 있던 0.28.2를 고정하며 다른 패키지 버전을 변경하지 않는다. pnpm 잠금 파일도 동일하게 맞춘다.

`.github/workflows/web.yml`은 공개 저장소의 표준 Ubuntu 환경에서 코드 변경 시 같은 검증을 실행한다. 읽기 권한만 사용하고 API 비밀 키는 전달하지 않는다. 첫 실행의 통과 여부는 실제 Actions 결과로 확인한다.

## 배포·운영 검증

수정본을 GitHub에 반영한 뒤 보호된 기존 Netlify 사이트의 배포 상태와 분리된 실사용 점검 공간에서 검증한다. 이번 버전의 실제 화면 결과는 확인 뒤 추가한다. 마이크·카메라·iPhone 공유·실기기 시험과 TestFlight 업로드·심사 제출은 별도 단계다.
