# 보이스그램 출시 계획

기준일: 2026-09-26 (한국). 목표: 2026년 10월 말 Google Play 테스트 후 공개 출시. iOS는 자체 테스트 후 App Store 심사·판매 준비. 심사 승인일은 확정하지 않는다.

제품: 일상, 여행, 취미, 추억을 자연스러운 한국어 대화로 만들고 수정하고 공유하는 개인용 창작 SNS. 업소 홍보에 한정하지 않는다.

## 목표 일정
- 9/26~10/4: 실제 대화 AI 연결, 문맥 편집·되돌리기 검증, 이미지·영상 생성 비용/한도 설계. 계정 유형 및 개발자 계정 접근 확인.
- 10/5~10/9: Android/iOS 패키징, 로그인·계정 삭제, 마이크·사진 권한, 생성물 저장/공유, 실기기 사전 테스트. 개인정보 처리방침·이용약관·스토어 설명 초안.
- 10/10~10/24: Google Play 비공개 테스터 테스트 목표. iOS 자체/TestFlight 테스트 병행. 음성 인식 오류·대화 맥락·생성 실패·결제 복원·계정 삭제·앱 중단 복구 점검.
- 10/25~10/31: 테스트 피드백 수정, 요건 충족 시 프로덕션 액세스 및 심사 신청, 승인 시 단계적 공개. iOS 심사 제출 준비. 심사 지연 또는 핵심 기능 미완료 시 공개 연기.

## 현재 상태와 출시 전 필수 작업
- 구현: 웹 편집/사진 업로드/PNG 및 브라우저 지원 영상 내보내기, 공유 확인, 대화 UI, 편집 이력 되돌리기, 서버 대화 API 어댑터.
- 연결: 자유 대화 AI 서버 환경변수 설정 및 실제 호출 HTTP 200 확인(2026-09-26). 운영 UI 실기기 검증은 대기.
- 미연결: 이미지·영상 AI 생성, 외부 SNS 직접 게시.
- 미구현: 상용 계정/DB, 자체 SNS 피드·팔로우·댓글, 신고/차단/운영도구, 앱 패키지, 스토어 결제/구독, 사용량 과금 한도, 오류 모니터링.
- 자체 SNS로 공개하려면 피드와 사용자 콘텐츠 운영 기능이 필요하다. 편집기 배포만으로 SNS가 완성된 것은 아니다.
- 판매 시작 전 생성 원가와 구독/크레딧 가격, 환불/복원, 실패 작업 미차감, 서버에서 결제 권한 검증을 확인한다. 가격 및 유료 서비스 가입은 별도 확정한다.
- 테스트용 공유 접근 코드는 상용 사용자 인증이 아니다. 공개 전 교체해야 한다.

## 스토어 조건 (2026-09-26 확인)
Google: 2023-11-13 이후 생성된 신규 개인 개발자 계정은 프로덕션 신청 전 최소 12명의 테스터가 연속 14일 비공개 테스트에 참여해야 한다. 계정 유형과 콘솔의 실제 요구사항을 확인한다. 날짜 경과만으로 출시가 자동 승인되지 않는다.
https://support.google.com/googleplay/android-developer/answer/14151465?hl=en

Apple: 자체 테스트 이후에도 App Review 심사를 통과해야 판매할 수 있다. 심사용 로그인, 작동하는 서버와 완성된 메타데이터를 준비한다. 웹사이트를 단순 포장한 앱에 그치지 않도록 모바일 핵심 경험을 검증한다.
https://developer.apple.com/app-store/review/guidelines/
https://developer.apple.com/distribute/app-review/
https://developer.apple.com/testflight/

## 확정이 필요한 입력
Google Play 개인/조직 계정 및 생성 시점, Apple Developer 계정, 테스트 참여자 명단, API 자격증명(보안 환경변수로 설정), 운영 주체/연락처, 판매 가격. 테스터 초대와 스토어 제출은 자료와 빌드 준비 후 진행한다.
