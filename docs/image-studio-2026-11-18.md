# 보이스그램 이미지 중심 제작

2026-11-18 한국 시각. 전 연령 대상, 익숙한 SNS와 음성 제작·게시를 결합한다.

## 구현 범위

- 기존 보유 바다·파티·팝아트·꽃 이미지 4종과 샘플 게시글. “1번 이미지 적용해줘”, “2번 문구 적용해줘”로 선택한다.
- “문구는 생일 축하해로 넣어줘”를 Canvas 제목으로 적용한다. 문구 수정과 샘플 적용은 AI 생성 API를 부르지 않는다.
- “대상을 사람으로 바꿔줘”는 선택한 원본을 참조하는 이미지 수정 요청으로 준비한다. 내용·비용 확인 이전에는 생성하지 않는다.
- 생성된 최근 3개 결과를 기기 초안에 보존하고 골라 게시한다. 이미 완성된 결과 선택은 재생성하지 않는다.
- 웹·iOS 웹 연결부에서 AI 이미지 진입을 제공한다. 기존 영상 업로드와 웹 영상 생성 어댑터는 유지하며 상세 영상 개발은 우선순위를 낮춘다.
- 서버의 이미지 제공자 레지스트리는 OpenAI 어댑터를 기본 제공한다. 추후 검증한 다른 제공자는 동일 인터페이스로 추가한다. 임의 클라이언트 주소·키·제공자 선택은 허용하지 않는다.
- 기존 gpt-image-1.5/low 기본값과 단일 이미지 생성을 유지한다. 최신 모델 자동 교체나 유료 생성 자동 재시도는 하지 않는다.

## 검증과 제한

기존 70개 및 새 이미지 명령·결과 복원·제공자 호출·중복 방지 검사 4개를 통과했다. TypeScript와 Netlify 빌드는 통과했다. 실제 유료 이미지·영상 생성은 실행하지 않았다. 사용자 음성을 실제 마이크로 인식한 시험은 아니다.

동일 브라우저 확장 연결이 originating context 오류로 실패했다. 별도 로컬 화면 확인 경로도 Site Unavailable 응답으로 막혔다. 새 UI의 화면 조작·실제 기기 저장·공유 확인은 미완료다.

최초 iOS CI는 프로젝트 파싱 오류로 실패했다. 프로젝트의 DEBUG=1 문자열에 따옴표를 추가했지만, 이 수정 뒤 Apple SDK 컴파일 결과를 확인하기 전에는 iOS 빌드 성공으로 보고하지 않는다.

브라우저별 기기 초안과 기존 시니어그램 자료는 자동 이관하지 않는다. 별도 후보 브랜치의 작품 보관함은 이번 변경과 병합하지 않았으며, 현재 운영본의 카드·내보내기 구현을 보존했다.
