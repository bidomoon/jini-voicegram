# 보이스그램 상품화 개발 — 2026-11-15

## 제품의 중심

시니어그램과 별개인 ‘말로 일상을 남기는 SNS’다. 기본 흐름은 마이크 → 이야기 → 사진/내 영상 선택 → 확인 → 게시 확정이다. 이용자가 처음 3분 안에 첫 게시물을 완성하고, 다음 날 또 남기고 싶은 순간을 떠올리게 하는 데 집중한다.

## 이번 구현

- 첫 게시 안내: 세 단계 설명과 짧은 이야깃거리로 시작한다.
- 재방문 화면: 실제 본인 게시물만으로 이번 주 게시 수·작성한 날·한국 날짜 기준 연속 작성일을 계산한다. 예시·미래 게시물은 제외하며 허위 인기 수치를 만들지 않는다.
- 홈 화면 설치: manifest와 180/192/512 아이콘, 지원 브라우저 설치 요청과 아이폰 Safari 안내. 인터넷 연결과 참여 권한은 여전히 필요하다. 오프라인 피드나 네이티브 앱스토어 배포를 뜻하지 않는다.
- 내 기록 내려받기: 본인의 프로필·게시글·댓글·활동 기록을 JSON으로 제공한다. 원본 미디어는 포함하지 않고 로그인용 링크를 제공한다. 타인의 신고·계정 토큰은 제외한다.
- 계정 삭제: 명시적 문구 확인, 본인 정보·관계·콘텐츠 제거, 재생성 차단, 파일 정리 재시도. 카카오 계정은 서버에서 확인한 해당 회원 번호로만 연결 해제한다. 키나 연결 해제 결과가 없으면 삭제 완료로 처리하지 않는다. 로컬 임시 초안·다운로드는 별도로 남는다.
- 운영 콘솔: 신고 검토·게시물 숨김·복원·검토 종료와 처리 근거 기록. Netlify가 확인한 운영자 ID 또는 서버의 카카오 세션과 명시적 allowlist만 허용한다. 숨긴 미디어 URL도 일반 사용자에게 반환하지 않는다.
- 만료 OAuth·세션 정리와 종료 계정 미디어 정리를 기존 주기 작업에 연결했다. 실행 시간·처리 수를 제한하고 다음 실행에 진행 위치를 이어간다.

## 판매 모델 제안 — 가격 미확정, 결제 미개시

기본 글·내 사진·내 영상 공유는 무료로 유지하는 안을 추천한다. 가입 직후 결제를 요구하면 핵심 경험을 하기 전에 이탈할 가능성이 있으므로 실제 베타에서 확인한다.

유료 후보는 AI 문장 편집·이미지 생성·보관량 확대이며 월 4,900~9,900원은 검증할 가격 가설이다. AI 영상은 공급자 원가가 크고 변동하므로 무제한 구독에 포함하지 않고 건별 크레딧으로 분리하는 안을 검토한다. 현재 유료 구독 원장·사용량 차감·환불 처리가 완성되지 않았으므로 이 가격을 판매 화면에 확정 공지하거나 실결제를 열지 않는다.

## 인기 여부를 판단할 베타 실험

초기 이용자 10~20명에게 7일간 사용하게 하고 아래 가설을 검증한다. 모집·외부 발송은 별도 사용자 지시가 있어야 실행한다. 아래 값은 실제 성과가 아닌 목표다.

| 지표 | 1차 목표 가설 | 확인 방법 |
| --- | --- | --- |
| 가입 뒤 첫 게시 완료율 | 60% 이상 | 동의한 베타 사용자의 시작·게시 결과 기록 |
| 첫 게시까지 걸린 시간 | 중앙값 3분 이내 | 실기기 관찰 |
| 다음 날 재방문 | 40% 이상 | 동의한 테스트 그룹의 확인 기록 |
| 7일 안에 3회 이상 게시 | 30% 이상 | 실제 게시 기록 |
| 음성 수정 도움 요청 | 사용자당 1회 이하 | 기기별 관찰 및 피드백 |

개인 추적 SDK나 외부 분석 도구는 새로 넣지 않았다. 운영 콘솔에는 기존 서버 기록에서 계산한 프로필·공개 게시물·최근 7일 작성자·대기 신고 수만 표시한다.

## 공개 출시와 유료 판매의 남은 조건

1. 보이스그램 전용 카카오 앱의 실로그인, 연결 해제, 다른 기기 복원을 검증한다. 필요한 설정: `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`, `KAKAO_ADMIN_KEY`.
2. 문의 연락처와 확정된 이용약관·개인정보 처리방침·커뮤니티 운영 기준, 신고 담당 및 응답 체계를 준비한다. 플랫폼 정책에 필요한 게시 전 유해 콘텐츠 차단도 별도 검증한다.
3. 현재 소규모 저장 구조(500 프로필·300 게시물·3,000 댓글)를 서비스 데이터베이스로 확장하고 백업·복구·부하 시험을 한다. 기존 데이터 이전은 백업과 검증을 선행한다.
4. 실기기 마이크·카메라·영상 재생·일반 네트워크에서의 업로드와 로그인 왕복을 검증한다.
5. 유료 이용권 원장·사용량·취소·환불·웹훅을 구현한 뒤 상점 계약과 결제 검증을 한다. 앱스토어/플레이스토어 출시 시 각 스토어의 디지털 결제 정책을 별도로 적용한다.
6. 일반 공개 전 기존 팀 SSO 해제 여부를 별도로 결정한다. 이번 배포는 보호를 유지한다. 공개 사이트 운영자는 검증된 카카오 UID allowlist 또는 별도 보호된 운영자 화면을 사용한다.

## 운영자 설정

- 기본 운영자는 Netlify에서 Owner로 확인한 기존 소유자 한 명이다. 서버가 검증한 사이트 ID와 사용자 ID가 모두 일치해야 한다. 다른 사이트로 복사하면 권한을 상속하지 않는다.
- `VOICEGRAM_MODERATOR_NETLIFY_IDS`: 기본 소유자 정책을 대체할 명시적 ID 목록. 빈 문자열로 설정하면 기본 권한도 비활성화한다. 다른 팀원에게 자동 부여하지 않는다.
- `VOICEGRAM_MODERATOR_KAKAO_UIDS`: 일반 공개 이후 사용할 보이스그램 내 카카오 사용자 UID 목록. 브라우저가 보낸 임의 UID는 사용하지 않는다.
- 추가 운영자 권한 목록과 카카오 admin key는 서버 functions 범위에 보관한다. 기본 사이트/소유자 ID는 인증 자격 증명이 아닌 공개 식별자이며 서버 정책 파일에 명시한다. 소스·클라이언트 번들에 넣지 않는다.
