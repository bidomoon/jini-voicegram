# 보이스그램 음성 게시 개발 — 2026-11-15

기본 음성 받아쓰기는 유료 AI 대화와 분리했다. 한국어 음성인식을 지원하는 브라우저에서 마이크를 눌러 글을 이어 적는다. 명령을 언급하는 일반 문장은 명령으로 실행하지 않는다.

- `내용 바꿔줘 ...`, `추가해줘 ...`, `방금 말 취소`로 글을 수정한다.
- `올려줘`/`미리보기` → 게시 전 확인 → `게시 확정`으로 올린다. 처음부터 확정 명령을 말해도 확인 화면을 먼저 연다.
- 확인 화면에서도 말할 수 있다. 내용을 수정하면 작성 화면으로 돌아가 다시 확인한다.
- `사진 선택`/`영상 선택`은 선택 경로를 표시한다. 기기의 파일 선택은 사용자가 버튼을 눌러 완료한다.
- 내 영상(MP4/MOV/WebM, 최대 20MB)과 60초 직접 촬영 경로를 추가했다. 기존 AI 동작 영상 생성은 별도 메뉴로 유지한다.
- 영상은 2MB 조각으로 전송한다. 소유자, 전체 해시, 조각 크기, 형식, 만료, 중복 게시를 서버에서 검증한다.
- 화면을 떠나거나 촬영창을 닫으면 카메라와 마이크를 해제한다.
- `npm run release:netlify`는 타입 검사 → 자동검증 → 프로덕션 빌드 → 함수 번들 → ZIP·검증 기록·해시 생성까지 실행한다. 실패하면 배포 묶음을 생성하지 않는다.

## 검증과 한계

오늘 복구본 기준 자동검증 28개, 타입 검사, 프로덕션 빌드가 통과했다. 브라우저 자동검증은 실행 환경에서 Chromium 소켓 생성이 차단돼 시작하지 못했다. 실제 휴대폰 음성·카메라, 운영 데이터 저장, 유료 AI 생성, 회원·결제는 이번 통과 판정에 포함하지 않는다. 이전 모의 음성 UI 시험 결과를 오늘의 실기기 검증으로 재사용하지 않는다.

운영 배포는 미완료다. 현재 공개 GitHub main에는 이 수정이 반영되지 않았다. 공개 코드 반영의 명시적 승인과 배포 접근 확보가 필요하다. 기존 Netlify 팀 로그인 보호를 해제하지 않는다.
