# 보이스그램 음성 게시 개발 — 2026-11-15

기본 음성 받아쓰기는 유료 AI 대화와 분리했다. 한국어 음성인식을 지원하는 브라우저에서 마이크를 눌러 글을 이어 적는다. 명령을 언급하는 일반 문장은 명령으로 실행하지 않는다.

- `내용 바꿔줘 ...`, `추가해줘 ...`, `방금 말 취소`로 글을 수정한다.
- `올려줘`/`미리보기` → 게시 전 확인 → `게시 확정`으로 올린다. 처음부터 확정 명령을 말해도 확인 화면을 먼저 연다.
- 확인 화면에서도 말할 수 있다. 내용을 수정하면 작성 화면으로 돌아가 다시 확인한다.
- `사진 선택`/`영상 선택`은 선택 경로를 표시한다. 기기의 파일 선택은 사용자가 버튼을 눌러 완료한다.
- 내 영상(MP4/MOV/WebM, 최대 20MB)과 60초 직접 촬영 경로를 추가했다. 기존 AI 동작 영상 생성은 별도 메뉴로 유지한다.
- 영상은 2MB 조각으로 전송한다. 소유자, 전체 해시, 조각 크기, 형식, 만료, 중복 게시를 서버에서 검증한다.
- 화면을 떠나거나 촬영창을 닫으면 카메라와 마이크를 해제한다.
- `npm run release:netlify`는 타입 검사 → 자동검증 → 프로덕션 빌드 → 함수 번들 → ZIP·검증 기록·해시 생성까지 실행한다. 실패하면 배포 묶음을 생성하지 않는다.

## 로그인·복구 보강

- 초대 코드 로그인을 `/api/auth?action=invite`로 분리했다. 기존 24자 이상 초대 코드와 32자 이상 기기 서명키를 그대로 사용하며 AI·카카오 설정이 없어도 참여한다.
- 카카오 미연결 시 초대 코드 입력을 첫 로그인 경로로 표시한다. 카카오가 연결된 경우 함께 제공한다.
- 로그인 전 IndexedDB 저장 완료를 기다린다. 글, 사진, 영상 Blob, 게시 번호, 미리보기 단계가 보존된다. 원래 초안의 저장 위치를 유지하므로 다른 계정의 기존 초안을 덮어쓰지 않는다.
- 영상 전송 중 401은 로그인 창으로 연결하며 작성 파일을 유지한다. 재참여 후 같은 게시 번호로 재시도한다.
- 영상 응답은 인증·게시물 공개 범위 확인 후 byte range를 지원한다. 잘못된 범위는 416으로 거부한다.
- 마이크의 늦게 도착한 시작 이벤트, 카메라 중복 연결, 사용 중인 리소스 해제를 보강했다.

## 검증과 한계

현재 소스의 자동검증 34개, 타입 검사와 프로덕션 빌드를 실행한다. 초대 로그인 → 실제 social 함수의 글 게시, 4MB 초과 영상의 조각 전송·게시·원본 조회·구간 재생·중복 방지, 로그인 왕복 시 영상 보존, 기기 저장 실패 시 이동 중단을 메모리 저장소에서 확인한다. 유료 API는 호출하지 않는다.

기존 배포 e99fb4e(2026-11-15 09:43 UTC)에서 실제 브라우저의 명령 입력 → 받아 적기 → 미리보기를 확인했다. 이 검증은 마이크 음성 입력과 다르다. Chromium 자동 실행은 환경의 소켓 제한으로 사용할 수 없으며, 운영 UI는 연결된 Chrome에서 확인한다. 실제 아이폰 음성·카메라·다른 기기에서의 재생은 아직 미검증이다.

## 배포와 상용화 경계

GitHub main과 기존 Netlify `jini-voicegram` 자동 배포 연결을 완료했다. 배포 결과는 별도 운영 검증 기록으로 남긴다. 기존 팀 SSO 보호는 유지한다. 이 릴리스는 초대형 모바일 웹 베타다.

공개 상용 출시는 카카오 실계정 연결·계정 삭제 및 복구, 약관·개인정보 처리방침 확정, 신고 처리 담당과 절차, 데이터베이스 확장·백업, 결제·구독 검증을 별도로 끝내야 한다. AI 동작 영상은 공급자 API 설정과 실제 생성 검증이 필요하다. 인스타그램 자체 계정에 자동 게시하는 기능은 이전 지시대로 보류한다.
